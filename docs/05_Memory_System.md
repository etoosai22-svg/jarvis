# JARVIS Project
## Part 5. Memory System

### 목표
JARVIS는 시간이 지날수록 사용자를 더 잘 이해하는 개인 AI 비서다.

### Memory 계층

#### Short-term Memory
- 현재 대화
- 현재 작업
- 최근 컨텍스트

#### Long-term Memory
- 사용자 선호
- 자주 가는 장소
- 즐겨 쓰는 서비스
- 반복 일정
- 프로젝트 정보

### 저장 원칙
- 사용자 동의 기반
- 수정 및 삭제 가능
- 민감정보는 저장하지 않음

### 활용 예시
> 사용자: '다음에도 부산은 KTX로.'
> JARVIS: '선호 정보를 기억하고 다음부터 KTX를 우선 추천하겠습니다.'

### MVP
- 대화 기억
- 사용자 선호
- 프로젝트 기억
- 일정 및 메모 연계
