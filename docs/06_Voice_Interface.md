# JARVIS Project
## Part 6. Voice Interface

### 목표
사용자가 실제 비서와 대화하는 것처럼 자연스럽고 끊김 없는 음성 경험을 제공한다.

### 기본 대화 흐름
> 사용자: 자비스.
> JARVIS: 네, 실장님.
> 사용자: 오늘 일정 알려줘.
> JARVIS: 오전 10시 회의, 오후 2시 미팅, 저녁 운동 일정이 있습니다.

### 음성 처리 파이프라인
1. Wake Word (자비스)
2. 음성 인식 (STT)
3. 의도 분석
4. 작업 계획
5. MCP/도구 실행
6. 결과 생성
7. 음성 합성 (TTS)

### 응답 원칙
- 짧고 명확하게 답변
- 진행 중이면 현재 상태를 보고
- 완료 시 요약 브리핑 제공
- 필요한 경우에만 추가 질문

### 오류 처리
- 음성이 불명확하면 한 번만 재질문
- 네트워크 오류 시 원인 안내
- 도구 실패 시 대안 제시

### 향후 확장
- 블루투스 이어폰 자동 연결
- CarPlay 지원
- Apple Watch 연동
- 음성만으로 예약 및 업무 수행
