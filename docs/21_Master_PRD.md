# JARVIS Project — Part 21. Master PRD

## 제품 비전
JARVIS는 사용자의 음성 명령을 이해하고, 조사·계획·실행·보고를 수행하는 개인 AI 비서 플랫폼이다.

## 핵심 목표
자연스러운 음성 대화 / 장기 메모리 기반 개인화 / MCP 외부 서비스 연동 / 승인 기반 자동 실행 / 빠른 신뢰성 있는 응답

## 핵심 기능
1. Voice Assistant  2. Memory  3. Task Manager
4. MCP Integration  5. Calendar  6. Search
7. Notes  8. Files  9. Notifications

## 비기능 요구사항
- 첫 음성 응답 2초 이내
- API 성공률 99%+
- HTTPS/TLS / OAuth 인증 / 감사 로그

## 기술 스택
- Frontend: React Native
- Backend: FastAPI
- DB: PostgreSQL + Redis + Vector DB
- AI: OpenAI API
