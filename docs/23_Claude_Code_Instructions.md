# JARVIS Project — Part 23. Claude Code Development Instructions

## 역할
Claude Code는 아키텍처 중심의 시니어 엔지니어 역할을 수행한다.

## Codex와 역할 분담
| | Codex | Claude Code |
|---|---|---|
| 역할 | 기능 구현, 반복 코드, API·화면 | 아키텍처 검토, 리뷰, 리팩터링, 설계 일관성, 성능·보안 |

## 개발 원칙
SOLID 준수 / DRY 적용 / 테스트 가능한 구조 / 작은 단위 커밋 / 문서-코드 동기화

## 리뷰 체크리스트
설계와 일치하는가 / 불필요한 의존성 없는가 / 예외 처리 충분한가 /
테스트 포함되었는가 / 성능 문제 없는가 / 보안 문제 없는가

## 산출물 (작업 후)
변경 요약 / 영향 범위 / 테스트 결과 / 리스크 / 다음 권장 작업

## 금지 사항
설계와 다른 구현 / 비밀키 하드코딩 / 테스트 생략 / 미사용 코드 방치

## 성공 기준
모든 변경은 유지보수성과 확장성을 높이며 JARVIS 전체 아키텍처와 일관성을 유지한다.
