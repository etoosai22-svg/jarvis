# JARVIS Project — Part 19. Security Guide

## 보안 원칙
최소 권한 / Zero Trust / 기본 암호화 / 사용자 승인 우선 / 감사 가능성

## 인증
OAuth 2.0 / OpenID Connect / Access Token 단기 사용 / Refresh Token 안전 저장 / MFA 지원

## 권한 관리
사용자별 데이터 격리 / RBAC / 민감 작업 재인증

## 데이터 보호
TLS 통신 / 저장 데이터 암호화 / 비밀번호 저장 금지 / API 키는 서버에서만 사용

## 비밀키 관리
Secret Manager 사용 / Git 저장 금지 / 로그 출력 금지 / 주기적 Rotation

## 개인정보
최소 수집 / 삭제 요청 지원 / 기억 수정·삭제 기능 / 민감 정보 명시적 동의 후 저장

## 감사 로그
기록: 사용자 / 요청 ID / 작업 / 결과 / 시간 / 승인 여부 (민감 정보 마스킹)

## 외부 서비스
OAuth 기반 연동 / 권한 범위 최소화 / 토큰 만료 감지 / 연결 해제 지원

## 보안 테스트
침투 테스트 / 취약점 스캔 / 의존성 검사 / Rate Limit 검증

## 사고 대응
비밀키 폐기 / 세션 무효화 / 로그 분석 / 사용자 알림 / 복구 절차

## MVP 완료 기준
HTTPS 적용 / OAuth 인증 / 암호화 저장 / 감사 로그 / 비밀키 관리 / 기본 보안 테스트
