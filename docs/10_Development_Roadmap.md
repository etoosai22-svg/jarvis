# JARVIS Project
## Part 10. Development Roadmap

### Phase 1: MVP (2~4주)
- 음성 대화 / STT / TTS
- LLM 연동 (OpenAI API)
- Memory 기초
- 웹 검색
- 일정 조회
- 완료 기준: "자비스." 호출 후 자연스러운 음성 대화

### Phase 2: Personal Assistant
- 메일, 캘린더, 메모, 할 일
- 여행 계획, 예약 보조

### Phase 3: AI Operating System
- MCP 확장, 장기 Memory
- 자동 워크플로, 멀티 디바이스
- CarPlay, Apple Watch

### 기술 스택
- App: React Native (iOS + Android)
- Backend: FastAPI
- LLM: OpenAI API
- Database: PostgreSQL + Redis
- Memory: Vector Database

### 개발 우선순위
1. 음성 2. 대화 3. Memory 4. MCP 5. 자동화

### 성공 기준
말 한마디로 대부분의 개인 업무를 처리할 수 있는 AI 비서
